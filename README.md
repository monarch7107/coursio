# Coursio

Coursio is a Laravel 12 learning-resource directory for technology and business courses, with search, topic filters, and credential clarity.

## Features
- Responsive Blade UI with Tailwind CSS CDN
- Search by title, provider, description, or tags
- Topic and credential filters
- Direct links to official course providers
- Dockerfile for Railway deployment

## Deploy to Railway
Deploy the repository from its `main` branch using the included Dockerfile. The container generates an app key at startup when `APP_KEY` is not supplied and listens on Railway's `PORT`.

## Credential note
Course and credential rules can change. This is a curated starter directory, not a guarantee that every badge or certificate is free in every region or learning path. Confirm current terms on official provider pages.
